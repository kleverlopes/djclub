# DJ Club

Site do DJ Club: DJs para casamentos, festas e eventos.
O cliente monta a festa (ou pede para o DJ Club montar), e o pedido chega pelo WhatsApp para agendar uma reunião online.

Site estático: `index.html`, `logo.png` e `hero.jpg`. Para mudar WhatsApp, e-mail, canal do YouTube ou foto do topo, edite as constantes no começo do `<script>` em `index.html`.
